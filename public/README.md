# Public media assets

Upload your final media files into this folder with these exact names:

- `favicon-512.png` — 512×512 PNG used for browser icons, Apple touch icon, and the web manifest.
- `social-card-1200x630.png` — 1200×630 PNG used by Open Graph and Twitter/X link previews.

The actual PNG binaries are intentionally not committed here, so this branch stays text-only and easy to edit in GitHub. Use GitHub's file upload UI to add/replace those two files in this `public/` directory.

These files are referenced from the HTML as root-relative URLs:

- `/favicon-512.png`
- `/social-card-1200x630.png`
